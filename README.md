# Robotic Hand Project

This project is a **robotic hand** with moving fingers, designed in CAD. The idea is to use servos to pull strings that make the fingers curl—basically acting like tendons in a real human hand.

---

## Why did I make this project?

I wanted to learn how robotic hands really work and get hands-on experience with CAD and mechanical design. Seeing how robotic claws use strings to move, I thought it would be a cool challenge to design my own version using affordable hobby servos and a Raspberry Pi for control.
