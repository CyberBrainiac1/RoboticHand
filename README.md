# Robotic Hand Project

Hey! This is my project for designing a robotic hand that can move its fingers using servos and strings.

---

## What's in the repo?

- **CAD models of the palm:** The palm design has special holes for routing strings, just like how real tendons work.
- **Finger CAD files:** I made 3D models for the middle finger, ring finger, pinky, and thumb, each with spots for running strings through.
- **Base CAD:** There’s a base piece to help the hand stand up while testing and figuring out the best spots for servos and strings.
- **Assembly CAD:** I put together an assembly so you can see how the palm, fingers, and base all fit together.

---

## Design choices and ideas

- Switched from stepper motors (too bulky and expensive) to **servos** for moving the fingers—they’re easier to control and come in more sizes.
- The hand is meant to be controlled by a **Raspberry Pi** with a servo HAT, so it’ll be ready for coding and adding cool features later.
- Took inspiration from **Intuitive Surgical’s claws**, which also use strings to move their parts.
- Learned how to use more advanced CAD tools like custom planes, working with meshes, and building assemblies to visualize everything.
